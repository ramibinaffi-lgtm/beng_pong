# 🏓 Beng Bong

A classic, fast-paced arcade Ping-Pong game built from scratch using Python. Designed for simplicity, smooth gameplay, and quick local matches without requiring any external installations.

---

## 🎮 Features
- Classic Arcade Gameplay: Responsive paddle movement and dynamic ball physics.
- Zero External Dependencies: Powered entirely by Python's built-in turtle module.
- Score Tracking: Real-time score counter to keep track of every point.
- Clean Codebase: Lightweight, easy to read, customize, and expand.

---

## 🕹️ Controls
| Player | Move Up | Move Down |
| :--- | :---: | :---: |
| Player 1 (Left) | W | S |
| Player 2 (Right) | Up Arrow (↑) | Down Arrow (↓) |
